# 卡码网盘前端

前端和后端独立部署，API 路径前缀为 `/api/v1`。本地开发默认将 `/api` 代理到 `http://127.0.0.1:9090`。

## 部署开发服务器

公网或局域网访问时，Vite 必须监听所有网卡，并将 API 代理到实际后端地址。前后端在同一台机器时：

```powershell
$env:HOST = '0.0.0.0'
$env:API_TARGET = 'http://127.0.0.1:9090'
npm run dev -- --host 0.0.0.0
```

若后端在另一台机器，将 `API_TARGET` 改为后端可达的 HTTP 地址，例如 `http://10.0.0.20:9090`。不要把 API 目标写成访问者浏览器的 `localhost`。

Vite 开发服务器适合开发和临时联调，不建议直接作为生产静态站点服务。生产部署请运行 `npm run build`，用 Nginx 等 Web 服务器托管 `dist/`，并将 `/api/` 反向代理到后端；保持前后端同源可避免 Cookie 和 CSRF 跨域配置。

普通 API 请求在前端等待 15 秒后中止；文件上传和下载最多等待 10 分钟。该超时用于避免界面无限等待，后端若持续返回错误仍需检查服务器日志。
