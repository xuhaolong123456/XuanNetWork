# 个人知识图谱

## 页面

- 登录网盘后，从左侧“知识图谱”进入 `/drive/knowledge`。
- 图谱节点支持拖动；空白处拖动画布；滚轮或右上角按钮缩放。
- 搜索会保留匹配知识点及其直接关联节点。
- 详情面板支持编辑、删除知识点、添加和移除关系。

## API

接口均要求当前登录态。写操作使用现有 CSRF Cookie 流程。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/knowledge/nodes` | 获取当前用户的知识点 |
| POST | `/api/knowledge/node` | 新建知识点 |
| PUT | `/api/knowledge/node/{id}` | 更新知识点 |
| DELETE | `/api/knowledge/node/{id}` | 删除知识点及关联 |
| GET | `/api/knowledge/edges` | 获取当前用户的知识关系 |
| POST | `/api/knowledge/edge` | 新建关系 |
| DELETE | `/api/knowledge/edge/{id}` | 删除关系 |

知识点字段为 `id`、`title`、`content`、`category`、`createdTime`、`updatedTime`。关系字段为 `id`、`source`、`target`、`relation`。新建关系时，两个端点都必须归属于当前登录用户；越权资源统一按不存在处理。

## 本地启动

从项目根目录运行 `start-dev.bat` 启动现有前后端。也可以分别在 `backend` 运行 `mvn spring-boot:run`，在 `frontend` 运行 `npm run dev`。

本阶段复用现有 Spring Boot、MySQL/JPA、Redis 配置和 Vue 前端。AI 自动生成关系与向量搜索暂未接入。
