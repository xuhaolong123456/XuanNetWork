# 注册接口测试用例设计

## 1. 测试方法

注册接口使用等价类划分法和边界值分析法设计测试用例。

- 等价类划分：把输入划分为有效等价类和无效等价类，选取代表值验证规则。
- 边界值分析：重点验证规则允许范围的最小值、最大值，以及刚好越界的值。

## 2. 等价类测试

### 2.1 邮箱

| 用例 | 输入 | 类型 | 预期 |
|---|---|---|---|
| E01 | `user@example.com` | 有效等价类 | 校验通过 |
| E02 | 空值 | 无效等价类 | 提示“请输入邮箱” |
| E03 | 空字符串 | 无效等价类 | 校验失败 |
| E04 | 仅空格 | 无效等价类 | 校验失败 |
| E05 | `user-example.com` | 无效等价类 | 提示“邮箱格式错误” |
| E06 | `user@.example` | 无效等价类 | 提示“邮箱格式错误” |

### 2.2 昵称

| 用例 | 输入 | 类型 | 预期 |
|---|---|---|---|
| E07 | `user001` | 有效等价类 | 校验通过 |
| E08 | 空值 | 无效等价类 | 提示“请输入用户名” |
| E09 | 2 个字符 | 无效等价类 | 提示用户名长度错误 |
| E10 | 33 个字符 | 无效等价类 | 校验失败 |
| E11 | 已存在昵称 | 业务无效等价类 | 返回 `NICKNAME_EXISTS` |

### 2.3 密码

| 用例 | 输入 | 类型 | 预期 |
|---|---|---|---|
| E12 | `123456` | 有效等价类 | 校验通过 |
| E13 | 空值 | 无效等价类 | 提示“请输入密码” |
| E14 | 5 个字符 | 无效等价类 | 校验失败 |
| E15 | 65 个字符 | 无效等价类 | 校验失败 |

## 3. 边界值测试

| 字段 | 下越界 | 最小合法值 | 最大合法值 | 上越界 |
|---|---:|---:|---:|---:|
| 昵称长度 | 2，失败 | 3，成功 | 32，成功 | 33，失败 |
| 密码长度 | 5，失败 | 6，成功 | 64，成功 | 65，失败 |

邮箱长度上限为 128，当前单元测试重点覆盖邮箱格式等价类；后续可补充 128 和 129 字符的长度边界测试。

## 4. 业务规则测试

| 用例 | 场景 | 预期 |
|---|---|---|
| B01 | 正常注册 | 保存用户，密码为 BCrypt 密文 |
| B02 | 邮箱前后有空格且包含大写 | 转为小写并保存标准化邮箱 |
| B03 | 邮箱重复 | 返回 `EMAIL_EXISTS`，不保存 |
| B04 | 昵称重复 | 返回 `NICKNAME_EXISTS`，不保存 |
| B05 | 数据库唯一约束冲突 | 返回 `REGISTER_CONFLICT` |
