# 文件预览与文本上传

## 接口

`GET /api/v1/files/file/preview?fileId=123`

必须登录，`fileId` 是必填正整数。先通过数据库查询当前用户未删除的文件，再用存储根目录与数据库中的相对 `storageKey` 读取磁盘。数据库不保存绝对地址，响应不暴露存储路径。

成功返回 HTTP 200、`Content-Type: application/json`、`Cache-Control: no-store`：

```json
{
  "success": true,
  "code": "OK",
  "message": "操作成功",
  "data": {
    "fileId": 123,
    "name": "说明.md",
    "format": "md",
    "content": "# 文件内容\n"
  }
}
```

后端完整读取成功后才返回内容，前端完整接收、解析成功后展示；失败不展示部分正文。并发删除发生在归属查询之后时，本次已获准的读取可以完成，后续请求返回 404；已展示的内容不会自动撤回。

| HTTP 状态 | 业务码 | 场景 |
| --- | --- | --- |
| 400 | INVALID_PARAM | fileId 缺失、非整数、非正数 |
| 401 | UNAUTHORIZED | 未登录或登录已失效 |
| 404 | FILE_NOT_FOUND | 不存在、他人文件、已删除、目录、磁盘内容缺失或无效存储路径 |
| 413 | FILE_TOO_LARGE | 文件超过上限 |
| 415 | UNSUPPORTED_FILE_TYPE | 不是 md、txt 文件 |
| 415 | UNSUPPORTED_ENCODING | 不是合法 UTF-8 文本 |
| 503 | FILE_STORAGE_UNAVAILABLE | 磁盘读取故障 |
| 500 | INTERNAL_ERROR | 数据库故障 |

失败也使用 `Result`：`success: false`、上述字符串 `code`、中文 `message`、`data: null`。

## 上传约束

沿用 `POST /api/v1/files/upload`，multipart 的 `file` 字段和可选 `parentId` 查询参数，保留认证与 CSRF 校验。

- 仅接受 `.md`、`.txt`，扩展名大小写不敏感；前后端均检查。
- 单文件上限 **100 MiB = 104857600 字节**，恰好达到上限允许，超过返回 413。已有环境配置可以调低上限，但不能调高超过 100 MiB。
- multipart 整个请求上限为 101 MiB，为表单头预留空间。
- 零字节文件拒绝，按需求返回 **401 / EMPTY_FILE**，提示“不能上传空文件”。前端不会因此清除登录状态。纯空白内容不视为零字节文件。
- 预览支持 UTF-8（含 BOM）；上传成功不代表非 UTF-8 内容可以预览，预览时会返回 415。

## 页面与验收

- 单击文件图标、名称或文件行空白处，在当前标签页进入 `/drive/preview/:fileId`；复选框和操作按钮不触发预览。
- 独立预览页支持刷新；返回按钮保留来源目录与分页。目录点击行为不变，回收站不提供预览。
- txt 保留换行和空白，内容作为纯文本；md 支持标题、列表、表格、引用、代码块。
- Markdown 禁用原始 HTML、自动加载图片与相对链接；允许安全的 HTTP(S)、邮件和锚点链接。解析在工作线程执行，离开页面取消请求及解析。
- 加载时显示状态，404 显示“资源不存在”，其他失败显示具体原因并允许重试；遗留空文件显示“文件内容为空”。
- 自动回归检查：归属和软删除查询、存储路径边界、格式和编码、大小边界、HTTP 响应、Markdown 转义、空文件 401 不清除会话。

验证命令：后端 `mvn test`；前端 `npm test`、`npm run build`、`npm run test:e2e`。浏览器回归使用固定接口响应，不依赖本地账号与数据库；Windows 默认使用已安装的 Edge，其他环境需要安装 Playwright Chromium 或设置 `PLAYWRIGHT_CHANNEL`。
